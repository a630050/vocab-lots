# 詞彙抽籤系統 (Vocabulary Lots)

這是一個離線優先、基於瀏覽器運作的「詞彙抽籤與測驗系統」。
設計初衷是為了讓老師或家長能夠快速建立專屬的詞彙題庫，並讓學生透過抽籤的方式進行反覆練習。

🌐 **線上使用連結：[https://a630050.github.io/vocab-lots/](https://a630050.github.io/vocab-lots/)**

## ✨ 核心特色

- **完全離線運作 (Offline First)**：
  - 除了初次載入及「萌典 API」查詢注音需要網路外，所有資料（包含圖片）皆透過 `IndexedDB` 儲存在本地瀏覽器，不會上傳到任何伺服器，兼顧隱私與速度。
- **雙模式書庫建立**：
  - **🖼️ 圖片書庫**：只需選取本地電腦中的資料夾，系統會自動將資料夾內的圖片（`.jpg`, `.png`, `.webp` 等）匯入，並**以圖片檔名作為抽籤題目**。
  - **✏️ 手動書庫**：無需準備圖片，只需輸入文字即可逐筆建立測驗題庫。
- **自動注音查詢與校準系統**：
  - 系統內建串接**萌典 API**，抽籤顯示題目時會自動標示注音符號（以直式顯示）。
  - **注音校準**：如果遇到破音字或 API 辨識錯誤，可進入後台「注音校準」功能，逐字修正該詞彙的發音，系統將會全域記憶並套用您的修正。
- **直覺的後台管理介面**：
  - **書庫管理**：快速切換、總覽所有已加入的詞彙，支援快速刪除單一詞彙。
  - **系統管理**：可隨時一鍵清空抽籤紀錄，或重置整個應用程式的資料。
- **作答紀錄與統計**：
  - 抽籤後可標記「答對」或「答錯」，系統會記錄學習狀況，方便針對錯題進行後續複習。
- **快捷鍵支援**：
  - `空白鍵 / Enter`：開始抽籤 / 抽下一題
  - `A`：顯示答案視窗
  - `Esc`：關閉答案或對話框
  - `1`：標記為「答對」
  - `2`：標記為「答錯」

## 🚀 開始使用

1. 打開 **[線上版連結](https://a630050.github.io/vocab-lots/)**。
2. 點擊右上角 `⚙️` 圖示進入後台設定。
3. 於「新增書庫」分頁中，選擇建立**圖片書庫**（選擇本地圖片資料夾）或**手動書庫**。
4. 點選「書庫管理」分頁，可隨時查看目前書庫內的詞彙列表，或點擊「詞彙注音總覽與校準」來修改注音。
5. 關閉後台，在主畫面即可開始抽籤練習！

## ⚠️ 注意事項

- 本系統將圖片與設定儲存於瀏覽器的 IndexedDB 中。若您**清除瀏覽器快取 (Cookie 及網站資料)**，或是更換瀏覽器、使用無痕模式，將會導致資料遺失。
- 載入含有大量高解析度圖片的資料夾可能需要一些處理時間，建議將圖片適度壓縮後再匯入以獲得最佳體驗。
